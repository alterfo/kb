## Выборка

Импортированы статьи из трёх разделов, ближайших к
enterprise/docs/регламентному домену (операционка, тулинг, доступность):

- `tools` — git, docker, nginx, CI/CD, микросервисы, тестирование
- `recipes` — практические рецепты (GitHub, SSL, self-hosted)
- `a11y` — доступность (accessibility) и сопутствующие регламенты

Статья = путь `<section>/<slug>/index.md`. Практики (`practice/`),
демки, страницы авторов (`people/`), интервью и служебные `README`/
`LICENSE` в корпус не входят.

Итог: 298 документов → `testdata/ru-bench/corpus/doka/`.

## Импортёр

- Логика: `internal/bench/ruimport` (маркдаун → `corpus.Doc`, без сети)
- CLI: `cmd/kb-ru-import`

Команда воспроизведения (исходный снапшот репозитория склонирован в
`<src>` с pinned-коммитом):

```bash
go run ./cmd/kb-ru-import \
  -src <src> \
  -out testdata/ru-bench/corpus \
  -source-type doka \
  -sections tools,recipes,a11y
```

Идентификаторы документов детерминированы: `dsid_ru` + первые 10 hex
SHA-256 от относительного пути исходной статьи; slug — имя каталога
статьи. Заголовок берётся из frontmatter `title`, тело — markdown,
приведённый к plain text (без кода, картинок и разметки).
